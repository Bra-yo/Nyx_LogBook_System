Learning Area

A broad discipline or academic domain.

Example:

Computer Science

Information Technology

Cyber Security

Business Information Technology

----------------------------------

Competency

A skill area within a Learning Area.

Example

Programming Fundamentals

Networking

Databases

Artificial Intelligence

----------------------------------

Competency Group

A subdivision of a Competency.

Example

Programming Fundamentals

↓

Variables

Functions

Arrays

Pointers

Loops

----------------------------------

Learning Path

The collection of competencies assigned to a learner.

----------------------------------

Mentor

A professional responsible for mentoring learners in one or more competencies.

----------------------------------

Assessment

Evaluation of learner competency progression.

----------------------------------

Portfolio

A showcase of evidence proving competency achievement.
