# 10. Portfolio Engine

---

# Purpose

The Portfolio Engine is responsible for transforming a learner's internship journey into a professional digital portfolio.

Unlike a traditional CV, the portfolio demonstrates practical competency acquisition through evidence, projects, assessments, supervisor reviews, and achievements accumulated throughout the internship.

It acts as the learner's professional showcase while also serving as proof of competency completion for institutions and employers.

---

# Philosophy

The portfolio is not manually created.

Instead, it is automatically built from the learner's actual work inside BGHub.

Every approved activity contributes to the portfolio.

Nothing should appear inside the portfolio unless it has been verified by the system.

---

# Portfolio Data Sources

The portfolio aggregates information from multiple modules.

These include:

- Student Profile
- Learning Areas
- Learning Paths
- Competency Assessments
- Projects
- Milestones
- Logbook Entries
- Supervisor Reviews
- Evidence
- Certificates
- Achievements

- Projects completed
- Assessments

# Portfolio Generation Rules

Portfolio updates automatically whenever:

A competency is completed.

A project is completed.

A supervisor submits an assessment.

Evidence is approved.

A certificate is issued.

A learning path changes.

---

# Portfolio Integrity Rules

The learner cannot manually fake experience.

All displayed information must originate from verified BGHub data.

Deleted evidence is automatically removed.

Archived projects remain visible unless hidden by administrators.

Assessment history cannot be edited.
